# Vim
Vim 或者说是 Neovim 在我心中的地位也许是 Editor 里的 `NO.1` 吧。 这篇文章我会分享一下所有的东西（目前我所掌握的），包括插件、经验、观点等等

## Plugins
从一个基础的配置开始开发或者适配总是一件不错的事情。

我推荐 [kickstat.nvim](https://github.com/nvim-lua/kickstart.nvim), 它有着详细的文档注释和一套很基础但足够使用的基础配置，你可以看官方的介绍视频或者直接从 `init.lua` 入口开始一行行学习 `lazy.nvim` 是如何管理你的插件系统的，以及一些 Vim 的常规配置，例如：relative line number, keymap, color, clipboard 等等, 下面是几个我认为你可以额外尝试的插件:
 
- [compile-mode.nvim](https://github.com/ej-shafran/compile-mode.nvim) 如果你使用c, rust 这样的编译型语言, 这个插件能够让你你快速的多次的进行编译尝试，这在项目开发和学习过程中十分方便，它起源于 [Emacs](https://www.gnu.org/software/emacs/), 另一款古早的 **"文本编辑器"**
- [markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim) 一个打开浏览器预览Markdown的插件, 我现在就在使用
- [leetcode.nvim](https://github.com/kawre/leetcode.nvim) LeetCode 不提供 LSP, 也许你可以试试在 Neovim 里刷题 :)
- [toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim) 使用它可以在 Neovim 里打开一个类似终端的东西, 很像 Vscode 里我可以随时调起的终端，但是即使我使用的是 Kitty ,在这个终端里它也不能显示图片, 所以可以给到人上人 :>
- [molten.nvim](https://github.com/benlubas/molten-nvim) 对于机器学习的同学来说, Jupyter Notebook 是一大神器，这个插件对它的支持比较全面，但是配置起来也较为繁琐, 不得不说这一点 Zed 和 Neovim 都没有 Vscode 做的好

## Operator & Motion
查看 `:Tutor` 是一个入门 vim 的很好方式, 相信你会学习到 \[Number\] + \[Operator\]  + \[Motion\] 这是 Vim 基本功, 我认为这同时也是 Vim 作为一款文本编辑器的核心理念（什么操作，对象是谁，操作多少次）

> Vim 是一种 **高效的, 自定义和可扩展性极强** 的编辑器, 我经常觉得惭愧, 明明我的工作流存在可以优化的地方，可我总是保持原来的坏习惯，而导致低效的编辑。所以请你我: Keep Learning, Keep Imporving.

## Buffer
Buffer 又叫缓冲区域，是指把文件读取到内存中的映射, 用 Neovim 打开一个文件，就相当于把一个文件或者目录读取到了内存中，然后把文件中的内容显示在屏幕上，当我们按下 `:w` 之后他便写回硬盘, 这里的视图很重要, 这里可以玩很多 **tricks**, 例如使用 `:vs` , 就可以实现左右分屏，后面可以跟一个文件路径的参数，这样他就能打开这个文件放到右边，上下分屏 `:split` 也是同理，当屏幕被分成两个部分以后，我们叫他们 `window`, 它并不是一个新东西，它只是 Buffer 的一种呈现形式而已, 在我们面前呈现的 Buffer (Window)，这中感觉很奇妙。

Vim 关于 Window 有一个专门的 `prefix key` 是 `<C-w>` 按下它再介绍 `jkhl` 或者你还可以按住 `<Shift>` 就可以 '移动' 窗口了, 按下 `_` 或者 `|` 则可以调整他们的最大高度或者是宽度，按 `+` 或者 `-` 则可以一点点调整， `o` 是 only, 全屏显示，这和前面的最大有区别，前面的最大会保留 window ，只是它比较小而已，但是 `o` 是只有这一个窗口存在了。当然你还可以直接按 `<C-h>` 等等来在窗口中移动，或者用 `:resize` 这些命令来直接调整窗口等等

事实上，这里还有一个名词叫做 `tab` (其实他也只是 Buffer 的一种表现形式，告诉我们这里还有几个 Buffer 在我们看不到的地方), 他通常指的是我们屏幕上方或者最下面那几个分隔开的标签，例如 `firfox` 浏览器里的标签在 Neovim 或者终端里叫做 Tab, 我并不是很喜欢它，所以我的 Neovim 里并没有安装对应的插件，浏览器里也是垂直标签栏

如果你了解 `tmux` 那上述内容对你来说一定很简单, 和 `tmux` 类似, 在 Buffer 之上还有一个更大的单位叫做: `Session` 他会保留你的当前编辑的所有，包括 Window Buffer 等等，你可以用以下命令创建和加载 Session:

```bash
:mksession [filename.vim] # 创建 Session
```

```bash
:source Session.vim # 在 Vim 内部加载 Session
```

```bash
vim -S Session.vim # 启动 Vim 的时候加载 Session
```



## Tips
1. `zz` `zb` `zt` 可以很方便的调整当前 Vim 的视图
2. `m[a-z]` 可以打标签，再配合 `'[a-z]` 实现快速跳转, 使用大写字母可以跨文件跳转
3. `<C-o>` 可以跳回原来位置, 配合 `<C-p>`, `gd` (Go to definition) 可以快速查看某个函数的定义
4. `.` 和 `宏` 很有用, 但同时也很难掌握
5. `gU` 也是一个 'Operator' 可以把选中的东西变成大写, `gu` 则是小写, 配合 `iw` 之类的 `textboject` 可以快速把整个单词变成大写字母或者小写字母，这在定义常量的时候很有用
6. Telescope 应该是我使用最频繁的一个插件了，可以通过它 search 任何东西，包括`<leader>sf` 查找文件, `<leader>sg` 配合 ripgrep 来查找包含某个关键词的文件
7. auto_command 和 user_command 事实上可以配合完成很多有意思的东西, 也许我应该新开一篇文章
8. `tab` 键很重要 (记住这一点)
9. `help` really matters
